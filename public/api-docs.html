Autenticação
Todos os endpoints exigem o header api_access_token
💡 Inclua o header api_access_token: SEU_TOKEN em todas as requisições. Você pode obter seu token em Perfil → Token de Acesso dentro da plataforma.
Todas as rotas seguem o padrão:
{domínio}/api/v1/accounts/{account_id}/[recurso]

O Account ID pode ser encontrado na URL do navegador ao acessar a plataforma (ex: /app/accounts/1/...).
cURL — Exemplo base 
curl -X GET "https://seu-dominio.com/api/v1/accounts/1/patients" \
  -H "api_access_token: seu_token" \
  -H "Content-Type: application/json"
